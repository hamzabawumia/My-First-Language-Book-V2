# Adding More Concepts and Categories

How to grow the book past 200 concepts (or add a new topic) without breaking the app.
Tested procedure: adding concept `201` to all four packs and running `tools/build.py` passes cleanly; leaving one pack without a word makes the build stop with a clear message.

---

## The golden rules

1. **Only ever add to the END.** The next concept after `200` is `201`, then `202`, and so on.
2. **Never renumber, reorder, delete or reuse an ID.** Pictures, words, audio, quiz/spelling and each child's saved progress are all matched by ID. Reordering silently pairs the wrong picture with the wrong word.
3. **Every language pack needs a word for every new ID.** One missing word in one pack stops the build (and blocks that language in the app).
4. **Always run `python3 tools/build.py` afterwards.** It validates everything and refreshes the offline copy.
5. **Concepts `001`–`010` are locked** (a check in `app.js` expects baby, mother, dog, banana, cup, ball, car, tree, eat, sleep). Don't edit those.

---

## Quick checklist (adding one or many concepts)

- [ ] 1. Append the concept(s) to `data/concepts.json`
- [ ] 2. Add the word for each new ID to **every** `languages/*/pack.json`
- [ ] 3. (Optional) Add pictures `images/201.jpg` (or `.png`)
- [ ] 4. (Optional) Add audio `languages/<code>/audio/201.mp3`
- [ ] 5. Run `python3 tools/build.py` and confirm it ends with `OK`
- [ ] 6. Hard-refresh the browser (the first time, on each device)

---

## Step 1: `data/concepts.json`

Add new entries at the **bottom** of the list, after the `200` entry. Mind the commas: every entry except the last needs a comma after its `}`.

```json
  { "id": "200", "category": "concepts", "concept": "love", "visual": "❤️" },
  { "id": "201", "category": "school", "concept": "pencil", "visual": "✏️" },
  { "id": "202", "category": "school", "concept": "book", "visual": "📖" }
]
```

| Field | Rules |
|---|---|
| `id` | Next number in sequence, three digits, in quotes. No gaps, no duplicates. |
| `category` | Lower-case, no spaces (use `_`). Becomes a topic (see "Categories" below). |
| `concept` | The English word. Shown as the English hint. |
| `visual` | One emoji. Shown until a real picture exists. |

## Step 2: every language pack

In each `languages/<code>/pack.json`, add the same IDs inside `translations`:

```json
    "200": { "word": "amour" },
    "201": { "word": "crayon" },
    "202": { "word": "livre" }
```

Do this for **all** packs (`fr`, `es`, `ga`, `tw`, and any you've added). If you only have words for some languages, add the others later, but the build will not pass until every pack has every ID. Tip: ask an AI to translate your new concept list into each language, then paste the results in the same `"id": { "word": "..." }` format.

## Steps 3 and 4: pictures and audio (optional)

- Picture: `images/201.jpg` (or `.png`). Until it exists the emoji is shown. See `02a. ADDING_IMAGES.md`.
- Audio: `languages/fr/audio/201.mp3`. Without it, the browser's built-in voice is used when one exists for that language.

## Step 5: build

```bash
python3 tools/build.py
```

Success looks like:

```
  fr     Français     words 202/202   audio 200/202
  ...
OK — languages: fr, tw, es, ga  (cache xxxxxxxx)
```

If it prints `Problems found`, read the message. It names the language and the first missing IDs. Fix, then run it again.

## Categories (topics)

Categories drive the **topic picker** in Learn, Quiz and Spelling. Nothing else needs registering.

- **Using an existing category:** just type its exact name (`animals`, `food`, `people`, `home`, `actions`, `clothing`, `toys`, `transport`, `nature`, `body_feelings`, `concepts`). A typo (`animal`) creates a separate, one-word topic, so copy the name exactly.
- **Creating a new category:** just use a new name in `concepts.json` (e.g. `"school"`). A new topic card appears automatically. The title is made from the name (`body_feelings` → "Body & feelings").
- **Topic icon (optional):** new categories show a ⭐ by default. To give one its own emoji, open `games.js`, find `const ICONS = {` and add a line, e.g. `school: "🎒",`.
- **Don't rename a category once children have used the app.** Their saved quiz/spelling scores are stored under the category name, so a rename makes the old scores disappear (learned-word progress is stored by ID and is not affected).
- **Aim for 10 or more concepts per category.** Quizzes always have 10 questions and need wrong answers to choose from. A smaller topic still works, but the quiz fills the remaining questions with words from other topics, so it won't be purely that topic.
- **Order:** topics appear in the order they first show up in `concepts.json`.

## Tips for words (spelling game)

- **Spelling needs at least 3 letters** in a word. Concepts whose words are shorter than that (in a given language) are skipped in the spelling game. That is fine, they still work in the book and quiz.
- **Phrases are fine** (e.g. *brosse à dents*). The spelling game picks one word from the phrase.
- **Special letters:** accents (é, ñ, ü…) are forgiven automatically. For other letter shapes (like Twi/Ga **ɛ ɔ ŋ**), the app needs to know the nearest plain letter. If you add a language with new special letters, add them in `games.js`:
  ```js
  const SPECIAL = { "ɛ": "e", "ɔ": "o", "ŋ": "n" };   // add e.g. "ø": "o"
  ```
  and add the same letters to the matching `.replace(/[ɛɔŋ]/g, ...)` pattern in the `fold` line just below. Without this, a child typing the plain letter will be marked wrong.

## What happens to existing progress

- Children's **learned words** are saved by concept ID, so adding concepts never loses anything. A topic that was "✓ Learned all" will show e.g. "Learned 25 / 27" until the new pictures are seen.
- Best quiz and spelling scores are kept.

## Common mistakes and how to fix them

| Symptom | Likely cause | Fix |
|---|---|---|
| Build says `missing words for N concepts` | A pack is missing the new IDs | Add them to that pack |
| Build says `unknown concept IDs` | A pack has an ID that is not in `concepts.json` | Add the concept, or remove the stray word |
| Page shows "Could not load the book" | JSON typo (extra/missing comma, quote) | Paste the file into a JSON checker, or run `python3 -m json.tool data/concepts.json` |
| "Concept IDs must run 001..N" | A gap, duplicate or out-of-order ID | Make IDs continuous: 001, 002, … with no gaps |
| New words don't show on a phone/tablet | Old cached copy | Run `build.py`, then hard-refresh or close and reopen the app |
| A new topic shows only ⭐ | No icon set | Optional: add it to `ICONS` in `games.js` |
| Wrong picture next to a word | An ID was reordered or reused | Restore the original order; only append |

## Before you publish

1. `python3 tools/build.py` → must end with `OK`.
2. Open the app, pick the new topic under **Learn**, and check a few words look right.
3. Take one quiz and one spelling round on the new topic.
4. Commit **everything** the build changed: `data/concepts.json`, the pack files, `data/embedded.js`, `languages/index.json` and `sw.js`.
